# 🚚 NOURR TRANSPORT - Site Web Professionnel

Site web complet pour l'activité de transport de colis entre la France et la Tunisie avec système de suivi QR intégré.

## 📋 Caractéristiques

✅ **Design professionnel et responsive**
- Interface moderne et intuitive
- Compatible mobile, tablette et desktop
- Couleurs premium (bleu + turquoise)

✅ **Formulaire de devis en ligne**
- Calcul automatique pour colis standard (4€/kg)
- Devis personnalisé pour électroménager/électroniques
- Champs complets : origine, destination, description

✅ **Système de suivi de colis avec code QR**
- Code de suivi unique par colis
- Historique détaillé de livraison
- Statuts : En attente → En transit → Livré

✅ **Pages principales**
- Accueil avec présentation
- À propos avec statistiques
- Services et tarifs
- Zones de couverture (France + Tunisie)
- Formulaire de contact
- Section de suivi de colis

## 🚀 Installation et utilisation

1. **Cloner le repository**
   ```bash
   git clone https://github.com/mte9375-star/nourr-transport-website.git
   cd nourr-transport-website
   ```

2. **Ouvrir le site**
   - Ouvrez simplement `index.html` dans votre navigateur
   - Ou utilisez un serveur local (Python, Node.js, etc.)

3. **Utiliser en ligne**
   - Hébergez sur GitHub Pages, Netlify, Vercel, ou autre hébergeur
